# story-chapter-craft：章节创作要点

本 Skill 只做一件事：在写正文的当下把常见的结构与表达问题挡在前面。
它不要求读文件、不运行脚本、不派发 subagent；下面是可直接执行的清单，与项目模板给出的
大纲、角色、伏笔、前情同级遵守。**剧情事实优先于本清单**：任何一条若与既定事件、动机、
结果、揭露顺序冲突，按剧情写。

## 一、章节结构

- 开头有钩子，不从天气、风景、日常流程起手；主角尽快出场，危机或卖点在前 300-500 字可见。
- 中段必须有事件发生：场景有目标、有阻碍、有变化，结束后局势与开头不同。
- 章尾落在变化上（危机 / 决定 / 发现 / 反转至少一项），不做总结、感慨、点题或「新的一页」。
- 推进主线 / 关系 / 设定中的至少一项；删掉这段不影响理解，就别写。
- 一章不塞超过 3 个新概念，设定跟着冲突走，不写大段说明文。

## 二、情绪与细节

- 情绪没有固定译法。上下文已经成立就不补动作；情绪改变了下一步，就写角色说了什么、
  撤回了什么、改了哪条路、付了什么代价；正在处理的物件出了什么变化。
- 只有「指尖、指节、目光、嘴唇、呼吸、袖口 + 轻微动作」而没有后果的，删掉，不换部位。
- 一句准确的直写（「他听烦了」）可以留；不为避开普通情绪词绕成三十字表演。
- 同一情绪只取最有信息量的一处，不把「动作 + 身体 + 比喻 + 心理解说」叠成四重注释。
- 危险、碰不得、厉害不由叙述者断言，由一次有代价的试探演示，把发现权留给读者。

## 三、声口与对白

- 台词回到对象、场合、意图：他在求助、敷衍、试探，还是公开表态。
- 不同人说话方式不同；所有人都用同样完整的解释、同样漂亮的反问时，按身份与上下文恢复差异，
  不靠加俚语、粗话、口误装自然。
- 不把每项条件转成一行问答，让人物照着提纲对接信息。

## 四、避免 AI 腔（表达层）

- 不写电报体：不要把位置、原因、动作拆成一串各说一事的短句；先定这段在写哪次行动，再按主次组织句子。
- 不用否定翻转铺垫：少写「不是 A，而是 B」「没有 X，没有 Y，只有 Z」；纠错、辩解、排除猜测时才保留对比。
- 不用万能状语与套式声线：「带着一丝…」「声音不大，却…」「语气毫无波澜」换成可辨的语气或具体信息。
- 不跨场景复用反应模板：「眼中闪过…」「嘴角勾起」「心头一震」「深吸一口气」。
- 不做抽象收束与预告：「意义深远」「从这一刻开始」「他不知道的是，更大的风暴即将来临」。
- 不解释已成立的事：删掉「这意味着」「真正重要的是」「他终于明白」这类结论链。
- 不用公文腔与论述腔：「不难看出」「事实上」「综上所述」「与此同时」；条文、职业对话、公告按自身语域写。
- 比喻要带信息：能给出角色特有感受、空间关系或新认识才留，只抬高语气就删，不换一批新比喻。

## 五、交付

只输出章节正文本身，不带标题、不带说明、不带自检报告、不带「以下是正文」之类的引导语。
字数按目标字数控制，不为凑字补无功能内容，也不为省字跳过关键过程。
